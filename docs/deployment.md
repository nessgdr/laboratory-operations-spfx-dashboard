# Deployment Approach

1. Build and test the SPFx project locally.
2. Bundle/package the production solution.
3. Upload the `.sppkg` package to the Microsoft 365 App Catalog.
4. Deploy/enable the solution for the tenant or selected sites.
5. Install the app on the Laboratory Operations SharePoint site.
6. Add the Laboratory Request Dashboard web part to the target page.
7. Validate permissions, REST calls, responsive behavior, and production data.
